プライバシーポリシー

self-resource は、開発者本人のみが利用する個人用ツールです。

取得する情報

Google アカウントの認可を受けたうえで、Google カレンダーの予定情報を取得・更新します。

利用目的

本人のアプリとカレンダーの予定を双方向に同期するためだけに使います。

保管と第三者提供

取得した情報と認可トークンは、本人のパソコン内にのみ保管します。広告や分析への利用はせず、第三者への提供・共有もしません。

Google API サービスのユーザーデータに関するポリシー

Google API から受け取った情報の利用と他のアプリへの転送は、限定的使用の要件を含む Google API サービスのユーザーデータに関するポリシーに準拠します。
